# Data

Raw files are **not** committed (licensing / privacy: the corpora contain real people's e-mails).

1. Download the Kaggle dataset *Phishing Email Dataset* (Naser Abdullah Alam, CC BY-SA 4.0):
   https://www.kaggle.com/datasets/naserabdullahalam/phishing-email-dataset
2. Put the six **per-source** files in `data/raw/` (keep the original spelling `SpamAssasin.csv`):
   `CEAS_08.csv, Enron.csv, Ling.csv, Nazario.csv, Nigerian_Fraud.csv, SpamAssasin.csv`
3. We do **not** use the pre-merged `phishing_email.csv`: it has no `source` column (needed for
   leave-one-source-out) and its text was already transformed by the dataset authors.
